# Changelog

## 1.0.5

### Added

- Hero: video support per slide (alongside images), autoplaying muted/looped/inline with lazy hydration for non-active slides
- Hero: unified the section into a single block-based structure (removed the separate static-hero code path)
- Hero: full-bleed image/video background with text overlaid directly on it, instead of a split text/image column layout
- Hero: letter-by-letter heading reveal animation, replayed per slide
- Shop by Category: horizontal drag/swipe-to-scroll row with infinite looping and continuous auto-scroll (pauses on hover, eases back in)
- Shop by Category: coverflow-style scale + 3D tilt effect on the centered category, responsive to both scroll position and mouse hover

### Changed

- Hero: gold accent color (badge, heading highlight, trust icons) replacing the previous mint green
- Hero: slideshow arrows repositioned to track the trust row's actual position instead of a fixed offset
- Shop by Category: background color, category card sizing, and category titles updated
- Adjusted hero section height across breakpoints

### Fixed

- Hero: scrim overlay was intercepting clicks on the slideshow arrows
- Hero: multi-slide text reveal only animated the first slide
- Shop by Category: native link drag-and-drop was interfering with the custom drag-to-scroll gesture
